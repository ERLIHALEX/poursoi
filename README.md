# POUR SOI — статическая версия для GitHub Pages

## Файлы сайта

- `index.html` — главная страница
- `spa.html` — каталог 20 SPA-программ
- `certificates.html` — подарочные сертификаты
- `school.html` — школа красоты
- `styles.css`, `app.js` — стили и логика сайта
- `school_poster.jpg` — изображение блока школы

## Размещение фотографий

Все фотографии категорий и SPA-программ загружаются **отдельными файлами в корень репозитория**, рядом с `index.html` и `app.js`. Вложенные папки `for_her`, `for_him`, `for_two` не нужны.

Ожидаемые имена файлов:
- Для неё: `her1.jpg` — `her11.jpg`
- Для него: `him1.jpg` — `him6.jpg`
- Для двоих: `us1.jpg` — `us3.jpg`

На главной странице используются `her2.jpg`, `us2.jpg`, `him5.jpg`. Для каталога 20 программ используются все 20 файлов с указанными именами.

На странице сертификатов карточки программ связаны с теми же фото: «Абсолютное восстановление» — `her1.jpg`, «Тайский Баланс» — `her2.jpg`, «СПА Выходной» — `her10.jpg`, «Королевский ритуал в 4 руки» — `her11.jpg`. Скрипт также перебирает расширения `.jpg`, `.jpeg`, `.png`, `.webp` и варианты регистра букв.

Для фотографий самого подарочного сертификата (верхний баннер и нижняя галерея) используются `serteficate1.jpg` и `serteficate2.jpg`, если эти файлы загружены в корень репозитория. Для блока школы используется `school_poster.jpg`.

## Публикация

В настройках репозитория GitHub Pages выберите публикацию из нужной ветки и корня (`/(root)`). Все HTML-файлы и изображения должны находиться на одном уровне в корне репозитория.

Формы в этой демонстрационной версии не отправляют реальные заявки на сервер.
