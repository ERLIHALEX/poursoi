# POUR SOI — полный статический комплект для GitHub Pages

В архиве есть все четыре страницы, общие CSS/JS, служебный файл GitHub Pages и афиша школы. PHP и Битрикс для запуска не требуются.

## Состав

- `index.html` — главная страница;
- `spa.html` — каталог 20 SPA-программ;
- `certificates.html` — подарочные сертификаты;
- `school.html` — школа красоты для девочек;
- `styles.css`, `app.js`;
- `.nojekyll`;
- `school_poster.jpg`;
- каталоги `for_her/`, `for_him/`, `for_two/` с файлами `ASSETS.txt`, где указаны ожидаемые оригинальные фотографии.

## Важное о фотографиях

Из сохранённых материалов удалось восстановить афишу `school_poster.jpg`. Оригинальные фотографии программ (`her1.jpg`–`her11.jpg`, `him1.jpg`–`him6.jpg`, `us1.jpg`–`us3.jpg`) и отдельные фотографии сертификатов (`serteficate1.jpg`, `serteficate2.jpg`) в доступных исходниках отсутствовали. Поэтому я не подменял их случайными или повторяющимися изображениями: карточки программ показывают фирменные текстовые заглушки, а на главной изображения категорий скрываются при отсутствии файлов. Для завершения визуального комплекта скопируйте ваши оригинальные изображения в соответствующие папки под указанными именами.

## Публикация

1. Распакуйте содержимое `poursoi-github-pages` в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main`, каталог `/(root)` и нажмите **Save**.

## Формы

Формы демонстрационные: они не отправляют персональные данные на сервер и не подтверждают запись или покупку. Они формируют текст заявки для копирования и самостоятельной отправки в MAX или Telegram.

Перед коммерческим запуском сверьте актуальность цен, условий сертификатов, программы школы и отзывов с владельцем салона.
