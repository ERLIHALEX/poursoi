# POUR SOI — обновлённый демо-сайт, 7 ноября 2026

В этом архиве — готовый статический сайт для GitHub Pages: `index.html`, `spa.html`, `certificates.html`, `school.html`, `app.js`, `styles.css`, `.nojekyll`, `poursoi-logo.png`, `school_poster.jpg`.

## Реализовано

- Сертификаты: **20 SPA-программ** (11 для неё, 6 для него, 3 для двоих), с ценами, названиями и фотографиями из того же каталога, что `spa.html`. Фильтры, поиск, просмотр состава и выбор сертификата.
- Сертификаты на **семь известных направлений услуг салона**: косметология, маникюр, педикюр, массаж, перманентный макияж, коллагенарий, брови и ресницы. Не выдуманы процедуры и цены, которых нет в утверждённом прайсе; можно указать конкретную услугу в заявке.
- Сертификат на **три мастер-класса** для девочек, сертификат на произвольную сумму.
- «Антистресс и релаксация» удалено как направление; на публичных страницах нет сообщения о его удалении.
- Школа пока остаётся как брендированный раздел практических мастер-классов. Претензий на лицензию или заявления об образовательной программе нет. Рекомендация согласовать название раздела с заказчицей.
- Оригинальный золотой логотип на тёмной шапке и в подвале. При ошибке загрузки картинки не появляется пустой прямоугольник или сломанная иконка.

## Установка на GitHub

1. Откройте https://github.com/erlihalex/poursoi
2. Распакуйте архив и **загрузите содержимое папки `poursoi`** в корень репозитория, заменив совпадающие файлы.
3. **Не удаляйте существующие фотографии**: `her1.jpg`–`her11.jpg`, `him1.jpg`–`him6.jpg`, `us1.jpg`–`us3.jpg`, `serteficate1.jpg`, `serteficate2.jpg`. Все они уже присутствуют в GitHub-репозитории и должны оставаться в корне рядом с HTML. В ZIP их копий нет.
4. Commit changes. После публикации откройте https://erlihalex.github.io/poursoi/certificates.html и обновите через Ctrl+F5.

## Важно перед передачей клиентке

- Есть только семь **направлений** услуг, а не утверждённый поимённый полный прайс процедур. Его нужно получить у заказчицы, чтобы действительно показать каждую отдельную услугу.
- Запрет на конкретные SPA-программы не указан. Сейчас показаны все 20 программ, присутствующие в прежнем каталоге. Если какие-то нельзя продавать по сертификату, попросите заказчицу назвать их точно.
- Название/наличие раздела «Школа красоты» и сертификаты на отдельные мастер-классы требуют подтверждения.
- Формы пока демонстрационные — формируют текст для отправки через мессенджер, не совершают оплату и не отправляют заявку на сервер.
